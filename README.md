# Tracki - Problem Solving Tracker

This is an application, that i personally use. I needed something to help me track the problems I solve on different coding platforms, tried excel, notion. did not work out for me. built something that had the features that i wanted, and nothing more. cause it seemed more fun to make something that does this, then adjusting to excel.

Made the backend using flask, and the frontend is in react.

**was hosted on azure, but azure postgres was costing too much, had to take it down, can be run locally, just run the start.sh file**
